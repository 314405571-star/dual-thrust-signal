## 0. 一句话

每天开盘时，用前 N 天的波动幅度画出上下两条线；突破上轨满仓，跌破下轨清仓，
另有大盘与个股两层止损兜底。

---

## 1. 通道

对第 t 个交易日，取前 N 根 K 线（严格是 `t-N .. t-1`，不含当天）：

```
HH = max(high)      LC = min(close)
HC = max(close)     LL = min(low)

range = max(HH − LC, HC − LL)
buy   = open[t] + k1 × range
sell  = open[t] − k2 × range
```

为什么取两个差的最大值：`HH − LC` 是"最高到最低收盘"的振幅，
`HC − LL` 是"最高收盘到最低"的振幅，取大者，通道对跳空更宽容。

`k1 = k2 = 0.5` 是经典参数——通道半宽等于当日波动的一半。

因为窗口在当天之前结束，通道在开盘时就是已知的，不存在未来函数。

---

## 2. 状态机

持仓只有两态：`shares = 0` 或 `shares > 0`（满仓）。每天按固定顺序检查：

| 顺序 | 条件 | 动作 |
|---|---|---|
| 1 | `index_pct < -3%` | 清仓（SELL_INDEX_STOP） |
| 2 | `close[t]/close[t-2]-1 ≤ -6%` 或 `close[t]/close[t-3]-1 ≤ -8%` | 清仓（SELL_STOCK_STOP） |
| 3 | `low[t] ≤ sell` | 清仓（SELL_DT） |
| 4 | `high[t] ≥ buy` 且空仓 | 以收盘价满仓（BUY） |

同一天里，止损先于通道卖出，卖出先于买入。若第 1 条触发，
第 2、3 条不会再执行——一笔交易只记录一次出场。

**成交价 = 当日收盘价。** 原始模块的注释写明这是简化：真实交易会在盘中触发，
成交价可能远好于或差于收盘。本仓库保留这个假设，以便与 notebook 对齐。

---

## 3. 绩效指标

```
总收益   = 期末权益 / 初始资金 − 1
年化     = (1 + 总收益)^(252 / 交易日数) − 1
最大回撤 = min(权益 / 历史最高权益 − 1)
交易次数 = BUY 的笔数
胜率     = 卖出价高于买入价的笔数 / 完整配对笔数
```

另外计算同期买入持有（首日收盘 → 末日收盘），作为对照。

## 6. 范围与局限

1. **不做有效性评估。** 仓库打包的是信号与回测引擎，demo 用合成数据展示机制。
2. **收盘价成交。** 日线通道在盘中就会被击穿，收盘成交是一个乐观或悲观的假设，
   取决于当天走势。
3. **无成本、无滑点、无仓位管理。** 满仓是用全部现金除以收盘价，允许小数股。
4. **前复权序列。** 复权基准随查询日变化，跨日重跑同一段历史，数值可能略有不同。
5. **单标的。** 原 notebook 与 demo 都只跑一只股票，没有组合层面的分散。
6. **止损优先级是写死的。** 大盘止损、个股止损、通道卖出同时满足时，只记录最靠前的一条。
